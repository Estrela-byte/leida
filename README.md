# 校园机会雷达

校园机会雷达是一款面向高校学生的校园活动与机会管理平台，目标是帮助学生快速发现适合自己的比赛、实习、项目、讲座、公益、科研和奖学金机会，并降低“信息分散、筛选成本高、风险信息不透明”的问题。

## 一、产品名称

校园机会雷达

## 二、解决的问题

在校园中，学生常常面临以下困惑：

- 信息分散：机会信息分布在公告栏、社交平台、邮箱、公众号等多个渠道。
- 过滤成本高：学生难以快速判断是否适合自己、是否值得投入时间。
- 缺失信息风险：很多活动信息存在时间不明确、主办方不清晰、报名门槛不明等问题。
- 参与决策困难：学生缺少一套清晰的“适配度 + 风险提醒 + 状态判断”工具。

校园机会雷达通过统一展示、智能筛选和学生发布入口，帮助学生更高效地管理和评估机会。

## 三、核心功能

1. 活动总览
   - 展示校园内外的机会信息，包括活动、招新、讲座、项目、实习和科研相关机会。
   - 每条信息都保留关键字段，如标题、类型、来源、主办方、对象、时间、地点、费用、要求和状态。

2. 筛选与搜索
   - 支持按活动类型、信息来源、状态和关键词筛选。
   - 提供统一搜索框，方便学生快捷定位目标机会。

3. 个人适配度评估
   - 提供“适配度”概念，帮助学生快速判断某项机会是否更符合自身方向和条件。
   - 支持标签化兴趣设置，例如开发、学习、设计等。

4. 用户行为记录
   - 通过浏览器本地生成 `user_id` 区分本地用户。
   - 支持收藏与报名记录，便于后续个性化推荐和数据分析。

5. 学生发布功能
   - 允许学生自行上报活动信息，补充校园内“非官方渠道”的机会池。
   - 上传的内容自动写入 SQLite 数据库。

6. 风险提醒与缺失信息提示
   - 对缺失信息例如报名方式、截止时间、主办方等进行显式展示。
   - 对风险提醒进行红色警示，帮助用户更谨慎判断。

## 四、运行方式

### 1）环境准备

确保已安装 Python 3.9 及以上版本。

### 2）安装依赖

在项目根目录执行：

```bash
python -m pip install -r requirements.txt
```

### 3）启动应用

```bash
python app.py
```

### 4）访问页面

打开浏览器访问：

```text
http://127.0.0.1:5000
```

### 5）跨平台说明

项目仅依赖 Python 标准库和 Flask，无需额外数据库服务，兼容 Windows、macOS 和 Linux。

## 五、创新功能

1. 本地优先的学生信息管理方式
   - 不依赖登录系统，使用浏览器本地 `user_id` 进行用户隔离，适合校园小型场景和本地演示。

2. 机会适配度与风险可视化
   - 把“适配度”与“风险提醒”直观展示到列表中，帮助学生迅速筛选真正值得投入的机会。

3. 数据透明度管理
   - 对缺失信息和风险项进行显式标注，而不是直接隐藏信息，增强用户信任感。

4. 面向学生的发布闭环
   - 从“只看信息”升级为“学生也能上报信息”，形成更活跃的校园机会共享生态。

## 六、关键问题处理

1. 数据不造假，信息保真
   - 项目中所有活动信息均按照真实来源信息整理，不人为编造缺失字段。
   - 缺失内容通过 `missing_info` 字段明确标出，而不是伪装成完整信息。

2. 自动初始化数据库
   - 首次运行时自动创建 `campus.db`，并导入默认数据，避免用户额外手动配置数据库。

3. 无 SQLAlchemy 约束
   - 数据访问直接使用 Python 标准库 `sqlite3`，符合项目要求，并降低依赖复杂性。

4. 即时筛选与响应
   - 前端使用 `fetch` 调用 Flask API，支持实时筛选、搜索、收藏和报名更新。

5. 兼容本地开发环境
   - 项目结构清晰，模板与静态资源分离，便于在不同平台上本地运行和调试。

## 八、下一步计划

1. 增强推荐逻辑
   - 基于用户收藏、报名和兴趣标签，增加更精准的机会推荐。

2. 增加提醒功能
   - 支持活动截止时间提醒、收藏提醒和报名提醒。

3. 扩展数据来源
   - 接入更多校内公告、公众号和官方平台数据，提升信息更新效率。

4. 提升管理后台能力
   - 增加审核、筛选和删除机制，提升内容质量控制能力。

5. 优化移动端体验
   - 继续提升移动端交互、信息密度和页面响应速度。

## 九、总结

校园机会雷达致力于把“分散的校园机会信息”转化为“易筛选、易评估、易参与”的一体化平台。它既帮助学生发现适合自己的机会，也让校园内部和学生个人发布的信息更容易被发现与使用。
