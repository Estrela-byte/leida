# 校园机会雷达

校园机会雷达是一款面向高校学生的校园活动与机会管理平台。它以“适配度 + 风险提醒 + 学生发布”的方式，帮助学生快速发现适合自己的机会，并降低信息分散、筛选成本高、详情不透明等问题。

## 一、产品名称

校园机会雷达

## 二、解决的问题

学生在校园中经常会遇到以下问题：

- 信息分散：机会信息分散在公告栏、社交平台、群聊和公众号中。
- 筛选成本高：很难快速判断哪些活动适合自己。
- 缺失信息风险：很多活动信息不完整，主办方、时间、报名方式等字段不清晰。
- 风险识别不足：学生很容易误判营销、广告或信息不实内容。

校园机会雷达通过统一展示、标签筛选、适配度评估和风险提示，降低这些问题带来的决策成本。

## 三、核心功能

1. 活动总览
   - 展示校园内外活动、招新、讲座、项目、实习和公益类机会。
   - 每条信息都保留关键字段，如标题、类型、来源、主办方、对象、时间、地点、费用、要求、状态等。

2. 智能筛选与搜索
   - 支持按类型、来源、状态和关键词搜索。
   - 适合在短时间内快速定位符合自己方向的机会。

3. 适配度评估
   - 通过兴趣标签与活动内容匹配，计算“适配度”。
   - 帮助学生判断某项机会是否值得投入时间。

4. 风险提醒与缺失信息提示
   - 对缺失信息做清晰展示。
   - 对营销性质、信息含糊、不完整信息采用红色风险提示。

5. 学生发布入口
   - 允许学生自行上报校园机会。
   - 发布内容会直接写入前端本地数据源，便于演示和 GitHub Pages 直接部署。

6. 本地用户隔离
   - 使用浏览器本地 `user_id` 区分不同使用者。
   - 不需要登录系统，适合演示场景和轻量校园应用。

## 四、运行方式

### 1）直接在 GitHub Pages 运行

本项目已改为纯静态前端页面，适合直接部署到 GitHub Pages。

- 直接将仓库推到 GitHub。
- 进入仓库的 Settings → Pages。
- 选择源分支并保存。
- GitHub Pages 会自动提供站点地址，例如：

```text
https://<你的用户名>.github.io/<仓库名>/
```

### 2）本地静态预览

如果需要本地预览，可在项目根目录执行：

```bash
python -m http.server 8000
```

然后在浏览器访问：

```text
http://127.0.0.1:8000
```

### 3）跨平台说明

项目不依赖后端运行环境，也不需要 Flask 或 SQLite 运行时即可展示页面，兼容 Windows、macOS 和 Linux。

## 五、创新功能

1. 纯静态 GitHub Pages 方案
   - 不依赖本地服务和数据库部署。
   - 更适合快速展示、教学演示和校园类项目展示。

2. 适配度 + 风险双维度评估
   - 用户不只看到“活动列表”，还能快速判断是否适合自己和是否存在风险。

3. 学生发布闭环
   - 学生既可以浏览信息，也能直接发布机会，形成更活跃的信息生态。

4. 信息透明度优先
   - 缺失信息和风险提醒不被掩盖，增强内容可信度和用户信任。

## 六、关键问题处理

1. 数据保真
   - 所有活动数据按原始信息整理，不人为编造缺失字段。
   - 真实缺失内容全部保留在 `missing_info` 字段中。

2. GitHub Pages 兼容
   - 页面完全由 HTML、CSS、JavaScript 组成。
   - 静态资源和入口文件均使用相对路径，适合直接部署。

3. 本地用户标识
   - 使用浏览器 `localStorage` 生成 `user_id`，避免依赖登录机制。

4. 体验设计
   - 页面采用白底蓝点设计、圆角卡片和红色风险提示，整体更加清爽和可读。

5. 低门槛运行
   - 无需安装复杂后端环境，适合课程作业、项目展示和校园活动汇总场景。

## 九、总结

校园机会雷达的目标不是单纯展示信息，而是帮助学生更快、更稳地判断“哪些机会值得参与、哪些可能存在风险”。通过纯静态 GitHub Pages 架构，它既保持了展示效果，也减少了部署门槛，适合高校场景快速落地。
